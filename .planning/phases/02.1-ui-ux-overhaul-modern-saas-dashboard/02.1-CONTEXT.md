# Phase 2.1: UI/UX Overhaul - Modern SaaS Dashboard - Context

**Gathered:** 2026-03-13
**Status:** Ready for planning

<domain>
## Phase Boundary

Transform the existing functional UI into a polished, modern SaaS dashboard with sidebar navigation, indigo color theme, Space Grotesk + Inter typography, a stats-driven dashboard home, and component polish across all existing views. No new capabilities — this is a visual and UX overhaul of what exists. Use the `frontend-design` skill for all design changes.

</domain>

<decisions>
## Implementation Decisions

### Navigation & Layout
- Collapsible sidebar navigation (expanded with labels, collapsed to icon-only rail)
- Sidebar sections: Dashboard, Recordings, Tasks (Phase 3 placeholder), Documents (Phase 4 placeholder), Settings (bottom)
- "Allure" text logo in Space Grotesk at top of sidebar
- Recording FAB stays in bottom-right corner (not moved to sidebar)
- shadcn sidebar component to be used — theme already has sidebar CSS variables

### Visual Identity & Theming
- Deep indigo primary color (#4F46E5 / oklch ~0.55 0.22 265)
- Lighter indigo for hover states and highlights
- Slate gray neutrals (cool-toned)
- Semantic colors: green for confidence ≥0.80, amber for confidence <0.80, red for errors/destructive
- Light mode only — no dark mode toggle
- Typography: Space Grotesk for headings, Inter for body text
- "Allure" brand text in Space Grotesk, text-only (no icon)

### Dashboard Home Screen
- Stats + recent activity layout
- Three stat cards: Total Recordings, Outcomes Extracted, Tasks Created
- Recent Recordings list below stats
- Recent Outcomes list below recordings
- Empty state: guided onboarding with "Record your first meeting" CTA and pipeline explanation

### Recording Hub Polish
- Keep existing table layout and tab bar filtering (All/Unassigned/Processing/Ready)
- Add text search bar for recording titles
- Add project dropdown filter
- Apply indigo theme to tabs and status badges
- Space Grotesk for page headings
- Better row hover states
- Refined status badge colors matching new palette

### Recording Detail & Outcome Cards Polish
- Indigo-themed tab bar (Info/Transcript/Outcomes)
- Confidence badges: green/amber with indigo accents
- Outcome cards: subtle borders, better shadows
- Transcript bubbles: refined speaker colors
- Summary banner: indigo accent treatment
- Space Grotesk for section headings

### Recording FAB Polish
- Match indigo theme: indigo primary when idle, red pulsing when recording
- Keep existing bottom-right placement and behavior

### Claude's Discretion
- Exact indigo shade tuning for light mode (oklch values)
- Sidebar collapse animation and trigger (button vs hover)
- Stat card visual design (icon treatment, number formatting)
- Recent activity list truncation and "view all" link behavior
- Hover/focus/active state details across components
- Loading skeletons and transition animations
- Exact speaker color palette for transcript bubbles (updated to complement indigo)
- Search debounce timing and UX details
- Empty state illustration/icon choices
- Placeholder content for Tasks and Documents sidebar items

</decisions>

<specifics>

- Clean, not cluttered aesthetic carried forward from Phase 2 context
