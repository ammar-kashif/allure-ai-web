Replace the entire `src/components/document/prd-content.tsx` with a react-markdown based implementation. Keep the same interface (`PrdContentProps` with `content: string`).

The new component must:

1. Import `ReactMarkdown` from `react-markdown`, `remarkGfm` from `remark-gfm`, and `rehypeSanitize` from `rehype-sanitize`.

2. Keep `"use client"` directive at top.

3. Keep the same outer container: `<div className="rounded-xl bg-card p-6 shadow-[var(--shadow-card)]">`.

4. Inside the container, render:
   ```tsx
   <ReactMarkdown
     remarkPlugins={[remarkGfm]}
     rehypePlugins={[rehypeSanitize]}
     className="prose prose-sm sm:prose-base dark:prose-invert max-w-none"
     components={{
       a: ({ children, href, ...props }) => (
         <a href={href} target="_blank" rel="noopener noreferrer" {...props}>
           {children}
         </a>
       ),
     }}
   >
     {content}
   </ReactMarkdown>
   ```

5. Use `max-w-none` on the prose class to prevent the typography plugin from constraining width (the parent card already handles width).

6. The `components` prop overrides links to open in new tabs with `target="_blank"` and `rel="noopener noreferrer"` per user decision.

7. `rehypeSanitize` with default schema strips raw HTML and images — no additional config needed for defense-in-depth.

8. Do NOT add syntax highlighting for code blocks — PRDs rarely contain code, basic monospace from prose defaults is sufficient per user decision.
