**Create backend/transcription.py** -- the core pipeline:

1. **Moonshine STT function** -- `transcribe_audio(wav_path: str, transcriber) -> list[dict]`:
   - Use the Transcriber from moonshine_voice with a FileTranscriptListener pattern (see RESEARCH.md Pattern 3)
   - Create a listener class that collects TranscriptLine objects via on_line_completed
   - Load audio with moonshine_voice.load_wav_file
   - Feed audio in chunks (chunk_size = int(0.1 * sample_rate))
   - Call transcriber.start(), feed chunks via transcriber.add_audio(), call transcriber.stop()
   - Convert TranscriptLine objects to dicts: `{"start": line.start_time, "end": line.end_time, "text": line.text}`
   - If TranscriptLine has a confidence attribute, include it; otherwise default to 1.0
   - Return list of segment dicts

2. **Diarization function** -- `diarize_audio(wav_path: str, pipeline) -> list[dict]`:
   - Run pyannote pipeline on the wav_path: `diarization = pipeline(wav_path)`
   - Iterate with `diarization.itertracks(yield_label=True)` to get (turn, _, speaker) tuples
   - Return list of `{"start": turn.start, "end": turn.end, "speaker": speaker}` dicts

3. **Alignment function** -- `align_transcript_with_speakers(transcript_segments: list[dict], diarization_segments: list[dict]) -> list[dict]`:
   - For each transcript segment, find the diarization segment with maximum time overlap
   - Assign the speaker label from the best-overlapping diarization segment
   - If no overlap found, assign "Unknown"
   - Return segments with "speaker" field added

4. **Speaker label remapping** -- `remap_speaker_labels(segments: list[dict]) -> list[dict]`:
   - Collect unique speakers in order of first appearance
   - Map pyannote labels (e.g., "SPEAKER_00") to "Speaker 1", "Speaker 2", etc.
   - Apply mapping to all segments

5. **Segment merging** -- `merge_consecutive_segments(segments: list[dict]) -> list[dict]`:
   - Iterate through segments; if current segment has same speaker as previous, merge:
     - Keep earlier start time, take later end time
     - Concatenate text with space
     - Average confidence scores
   - Return merged list

6. **Speaker stats** -- `calculate_speaker_stats(segments: list[dict], total_duration: float) -> list[dict]`:
   - Calculate talk_time_pct and utterance_count per speaker
   - Filter out speakers with <1% talk time (locked decision)
   - Sort by talk_time_pct descending
   - Return list of SpeakerStats-shaped dicts

7. **Main pipeline** -- `run_transcription(job_id: str, app_state) -> dict`:
   - Get job from storage to find wav_path
   - Get audio duration using torchaudio.info(wav_path).num_frames / torchaudio.info(wav_path).sample_rate
   - Run transcribe_audio(wav_path, app_state.transcriber)
   - Run diarize_audio(wav_path, app_state.diarization)
   - Align transcript with speakers
   - Remap speaker labels
   - Merge consecutive segments
   - Calculate speaker stats
   - Filter segments to remove any from speakers with <1% talk time
   - Return TranscriptResponse-shaped dict: {"id": job_id, "duration": total_duration, "language": "en", "speakers": stats, "segments": merged_segments}

**IMPORTANT research note on Moonshine Voice speaker ID:** The RESEARCH.md mentions Moonshine Voice may have built-in speaker_id on TranscriptLine. Check for it during implementation. If speaker_id is available AND accurate, it could replace pyannote for simpler setups. However, per research recommendation, use pyannote as the primary diarization approach since Moonshine's speaker ID is "not robustly evaluated." Code the pipeline to use pyannote. If Moonshine speaker_id is found available, log it but don't use it.
