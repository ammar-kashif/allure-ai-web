**backend/models.py** -- Pydantic models:
- `UploadResponse(id: str)` -- returned from POST /recordings
- `StatusResponse(status: Literal["pending", "processing", "completed", "failed"])` -- returned from GET /recordings/{id}/status
- `TranscriptSegment(start: float, end: float, text: str, speaker: str, confidence: float)` -- individual segment
- `SpeakerStats(label: str, talk_time_pct: float, utterance_count: int)` -- per-speaker stats
- `TranscriptResponse(id: str, duration: float, language: str, speakers: list[SpeakerStats], segments: list[TranscriptSegment])` -- full transcript

**backend/storage.py** -- In-memory job store:
- `jobs: dict[str, dict]` -- keyed by job_id
- `create_job(job_id: str, file_path: str, original_filename: str) -> dict` -- creates job with status="pending"
- `update_job(job_id: str, **kwargs) -> dict` -- updates job fields
- `get_job(job_id: str) -> dict | None` -- returns job or None

**backend/audio_utils.py** -- Audio format handling:
- `ALLOWED_EXTENSIONS = {".webm", ".mp3", ".wav", ".m4a", ".mp4"}`
- `validate_audio_format(filename: str) -> bool` -- checks extension against allowed list
- `convert_to_wav(input_path: str, output_path: str) -> str` -- runs `ffmpeg -y -i input -ar 16000 -ac 1 -c:a pcm_s16le output` via subprocess.run with check=True and capture_output=True. Returns output_path.

**backend/job_queue.py** -- Async job queue:
- `job_queue: asyncio.Queue = asyncio.Queue()`
- `async def process_worker(app_state)` -- infinite loop: await job_queue.get(), set status to "processing", call `run_transcription(job_id, app_state)` via asyncio.to_thread, set status to "completed" on success or "failed" on exception (store error message). Use try/finally with job_queue.task_done().
- `run_transcription(job_id: str, app_state) -> dict` -- STUB for now: sleep 1 second, return empty result dict `{"segments": [], "speakers": [], "duration": 0.0, "language": "en"}`. Plan 02 replaces this with real Moonshine + pyannote logic.

Important: The worker must import and use storage.update_job to change job status. Store transcription results in jobs[job_id]["result"].

**backend/main.py** -- FastAPI application:

1. Create FastAPI app with lifespan context manager:
   - On startup: create `uploads/` directory if not exists, start process_worker as asyncio.create_task (store on app.state.worker)
   - On shutdown: cancel worker task
   - Note: Model loading (Moonshine, pyannote) deferred to Plan 02 -- lifespan will be extended there

2. Add CORSMiddleware:
   - allow_origins=["http://localhost:3000"] (Next.js dev server)
   - allow_methods=["*"]
   - allow_headers=["*"]
   - allow_credentials=True

3. Health check endpoint:
   - GET /health -> returns {"status": "ok"}

4. Upload endpoint (POST /recordings):
   - Accept `file: UploadFile = File(...)` parameter
   - Validate file extension using audio_utils.validate_audio_format -- return 400 if invalid with {"error": "Unsupported audio format. Accepted: webm, mp3, wav, m4a, mp4"}
   - Generate job_id with str(uuid4())
   - Save uploaded file to `uploads/{job_id}_{file.filename}` using aiofiles (read bytes BEFORE response per pitfall #1)
   - Convert to WAV: call convert_to_wav to create `uploads/{job_id}.wav` -- handle subprocess.CalledProcessError, return 422 if ffmpeg fails with {"error": "Audio conversion failed"}
   - Create job in storage with create_job(job_id, wav_path, file.filename)
   - Enqueue job_id to job_queue
   - Return UploadResponse(id=job_id) with status 201

5. Status endpoint (GET /recordings/{job_id}/status):
   - Look up job with get_job(job_id)
   - If not found, raise HTTPException(404, "Job not found")
   - Return StatusResponse(status=job["status"])

6. Transcript endpoint (GET /recordings/{job_id}/transcript) -- STUB:
   - Look up job with get_job(job_id)
   - If not found, raise HTTPException(404, "Job not found")
   - If job["status"] != "completed", raise HTTPException(400, "Transcript not ready")
   - Return job["result"] (which will be a TranscriptResponse-shaped dict once Plan 02 implements real transcription)
