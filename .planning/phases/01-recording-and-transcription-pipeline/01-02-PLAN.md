6. Create Next.js API routes:

   `src/app/api/recordings/route.ts`:
   - GET: returns recordings from local SQLite (call getRecordings, optionally filter by status query param)
   - POST: receives multipart FormData with audio file + recordingId. Saves file to `~/.allure/recordings/{id}.webm`. Updates local DB with file_path. Proxies the file to FastAPI at `${BACKEND_URL}/recordings` (env var, default http://localhost:8000). Stores backend_id from response. Updates status to 'processing'. Do NOT set Content-Type header on proxy request (per research Pitfall 2).

   `src/app/api/recordings/[id]/route.ts`:
   - GET: returns single recording from local SQLite
   - PATCH: updates recording fields in local SQLite

   `src/app/api/recordings/[id]/status/route.ts`:
   - GET: proxies to FastAPI `${BACKEND_URL}/recordings/{backendId}/status`. Maps backend status to local status enum. Updates local DB if status changed. Returns current status.

   `src/app/api/recordings/[id]/transcript/route.ts`:
   - GET: proxies to FastAPI `${BACKEND_URL}/recordings/{backendId}/transcript`. Returns transcript with utterances array.

   `src/app/api/projects/route.ts`:
   - GET: returns projects from local SQLite
   - POST: creates new project in local SQLite, returns it

7. Create `src/hooks/use-recordings.ts` -- TanStack Query hooks:
   - `useRecordings(status?: RecordingStatus)` -- fetches recording list, refetches on invalidation
   - `useRecording(id: string)` -- single recording
   - `useRecordingStatus(id: string, enabled: boolean)` -- polls `/api/recordings/{id}/status` with refetchInterval: 3000ms when status is 'processing', stops (returns false) when 'ready' or 'error'. On status change to 'ready', invalidate recordings list query.
   - `useUploadRecording()` -- mutation that POSTs FormData to /api/recordings
   - `useAssignProject()` -- mutation that PATCHes recording with projectId, then triggers upload

8. Create `src/hooks/use-projects.ts`:

   - Update: The POST /api/recordings route should accept optional `projectId` in the FormData. If absent, save file + create DB record as 'unassigned'. If present, also proxy to backend.
