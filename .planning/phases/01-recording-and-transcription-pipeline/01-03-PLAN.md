   - Client component
   - Props: `recordingId: string, currentProjectId: string | null, onAssign: (projectId: string) => void`

   - If unassigned: render shadcn Select/DropdownMenu inline in the table cell

   - Selecting a project calls `onAssign(projectId)`

   - Client component

   - Switching tabs filters the table by status
   - Table uses shadcn Table components for styling
   - Each row is clickable -- navigates to `/recordings/{id}` detail page (use Next.js `useRouter`)
   - For any recording with status 'processing', enable status polling via `useRecordingStatus` hook
   - Show sonner toast when status changes from 'processing' to 'ready' ("Transcription complete!")
   - Show sonner toast on error ("Transcription failed" with error message)
